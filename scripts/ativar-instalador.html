Ativar instalador do Augi Gestão

  1. Gere um código exclusivo para a sua instalação.
  2. Envie o arquivo instalador.sha256 para storage/app/ na pasta privada do Augi.
  3. Informe o código abaixo em instalar.php.

Guarde o código em local privado. Cada nova geração baixa um arquivo que corresponde ao novo código.
